## 使用

启动Zookeeper：

nohup bin/zookeeper-server-start.sh config/zookeeper.properties &

启动Kafka：

nohup bin/kafka-server-start.sh config/server.properties &

创建Topic：

bin/kafka-topics.sh --create --topic test --bootstrap-server localhost:9092

查看Topic：

bin/kafka-topics.sh --describe --topic test --bootstrap-server localhost:9092


启动消费者：

bin/kafka-console-consumer.sh --bootstrap-server localhost:9092 --topic test

启动生产者：

bin/kafka-console-producer.sh --broker-list localhost:9092 --topic test

发送数据，消费者就能收到数据

## 集群

服务器地址：`192.168.1.221`

集群由一个 ZooKeeper 和三个 Kafka Broker 组成：

| 服务 | 监听地址 | 说明 |
| --- | --- | --- |
| ZooKeeper | `127.0.0.1:2181` | 仅服务器本机访问 |
| Kafka Broker 1 | `192.168.1.221:9092` | 外部可访问 |
| Kafka Broker 2 | `192.168.1.221:9093` | 外部可访问 |
| Kafka Broker 3 | `192.168.1.221:9094` | 外部可访问 |

客户端 Bootstrap Servers：

### 启动集群

```bash
/root/kafka-3.sh start
```

### 停止集群

```bash
/root/kafka-3.sh stop
```
### 查看日志

查看 ZooKeeper 实时日志：

```bash
tail -f /root/kafka-cluster/logs/zookeeper/zookeeper-root-server-docker01.out
```

查看三个 Kafka Broker 的实时日志：

```bash
tail -f /root/kafka-cluster/logs/kafka-1/server.log
tail -f /root/kafka-cluster/logs/kafka-2/server.log
tail -f /root/kafka-cluster/logs/kafka-3/server.log
```

启动失败时优先查看对应 Broker 的 `startup.out`：

```bash
tail -n 200 /root/kafka-cluster/logs/kafka-1/startup.out
tail -n 200 /root/kafka-cluster/logs/kafka-2/startup.out
tail -n 200 /root/kafka-cluster/logs/kafka-3/startup.out
```

## 创建⼀个分布式的Topic

./kafka-topics.sh --bootstrap-server localhost:9092 --create --replication-factor 2 --partitions 4 --topic disTopic

创建⼀个分布式的Topic

./kafka-topics.sh --bootstrap-server localhost:9092 --list

查看列表情况

./kafka-topics.sh --bootstrap-server localhost:9092 localhost:9092 --describe --topic disTopic
